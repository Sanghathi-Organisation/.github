 Sanghathi

**Connect. Mentor. Grow.**

Sanghathi builds practical digital tools for student mentoring and academic management in educational institutions.

Our platform brings student records, mentor-mentee coordination, academic and attendance tracking, feedback, communication, notifications, bulk uploads, and institutional reporting into role-based workflows.

## Contributing

Please read the contribution guide in the repository you want to change. Before opening an issue or pull request, check the existing documentation and follow the repository's setup, testing, security, and review guidance.

## Responsible Disclosure

Please do not report security vulnerabilities in public issues. Contact the Sanghathi team with a clear description and reproduction details. Never include passwords, tokens, student records, or other private data in an issue or pull request.

For product questions and collaboration, please contact the Sanghathi team through the official communication channel.
